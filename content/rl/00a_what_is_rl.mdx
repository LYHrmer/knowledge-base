# 第 0a 课：什么是强化学习（软启动篇）

> 假设你完全没听过 RL，只听说过"AlphaGo"、"ChatGPT"。
> 这一份**没有任何公式**，全部用日常例子。
> 读完你不会变专家，但会有一个**直觉地基**，让 L1 起的所有公式都有一个"长在脑子里的故事"可以挂。

---

## 0a.1 用一句话讲完

**强化学习 = 一个东西在环境里反复试，靠"做对了得糖、做错了挨骂"逐渐学会做正确的事。**

那个"东西"叫 **agent**（智能体）。
"环境"叫 **environment**。
"得糖 / 挨骂"叫 **reward**（奖励，正负都算）。

整件事就这三个词。其余都是它的细化版本。

---

## 0a.2 三个生活例子

### 例 1：训狗

```
你 → 喊"坐下" → 狗坐了 → 给零食 +1
你 → 喊"坐下" → 狗没动 → 不给 0
你 → 喊"坐下" → 狗跳起来 → 凶它一句 -1
```

狗是 agent，你 + 客厅是 environment，零食 / 凶骂是 reward。
重复 50 次，狗就学会"听到坐下→坐下"。

**这就是 RL 的全部本质**。机械臂学焊接、AlphaGo 学围棋、ChatGPT 学回答，都是这个套路的复杂版本。

### 例 2：玩电子游戏

```
你 → 按某个键 → 屏幕变化 → 通关 / 死了 / 拿到金币
```

你是 agent，游戏是 environment，分数是 reward。
玩 1000 次，你越来越会玩——你不知道游戏代码，但你**通过试错**学会了。
RL 算法在做的事情**完全一样**，只是它的"大脑"是神经网络。

### 例 3：小孩学骑自行车

```
小孩 → 蹬地 + 把把手 → 摔倒 → 痛（reward = -10）
小孩 → 蹬地 + 把把手 → 没摔 → 爽（reward = +1）
```

没人能用公式告诉小孩"重心偏 5° 时把手要反向 3°"，但他**自己摔几次就会了**。
**RL 不需要老师写规则，它自己从 reward 里学规则**。

## 0a.3 RL 三个朴素要素（不讲 MDP，先讲这个）

后面 L1 会教你"五要素"，这里先记**三个**：

### 1. 感知（看到什么）
狗听到"坐下"，眼睛看见你。这是它的"输入"。
机器人摄像头看到画面 + 关节角传感器读数。这是它的输入。

### 2. 行动（做什么）
狗可以坐 / 站 / 跳 / 跑。这是它的"输出"。
机器人可以让 6 个关节往某个方向转一点。这是它的输出。

### 3. 反馈（做完后世界给的回应）
狗吃到零食或被骂。
机器人焊缝走偏了 / 走对了。

```
       ┌───────── 环境（世界）─────────┐
       │                                  │
       ▼                                  │
   感知（看到）                            │
       │                                  │
       ▼                                  │
   决策（agent 大脑）                      │
       │                                  │
       ▼                                  │
   行动（做出来）─────→ 改变世界 ─────→ 反馈（reward）
                                          │
                                          ▼
                                       下一次循环
```

**学习的目标**：让"决策"那一步越来越好——好到能拿到尽可能多的 reward。

## 0a.4 RL 和"监督学习"的核心区别

监督学习（Supervised Learning, SL）你大概听过——给图片打标签是猫还是狗那种。

| 维度 | 监督学习 | 强化学习 |
|---|---|---|
| 数据来源 | 别人标好的（图 → 猫）| **自己跟环境互动产生** |
| 反馈 | "对/错"立刻知道 | reward 可能延迟（下完棋才知道赢没）|
| 目标 | 模仿标签 | **最大化未来累积 reward** |
| 训练过程 | 静态数据集 | **数据分布会随策略变化** |

**最大的区别**：
- SL 的世界里有一个"老师"在打分。
- RL 的世界里**只有反馈，没有标准答案**。环境只告诉你"你拿了 5 分"，不告诉你"你应该这么做才能拿 10 分"。
- 所以 RL 必须**自己探索**。

类比：
- SL = 看着别人的菜谱学做菜
- RL = 没有菜谱，自己尝，吃到好吃的就记住，难吃的就避开

## 0a.5 RL 能做什么 / 不擅长什么

### 擅长
- **决策序列**问题：下棋、玩游戏、机器人控制——一连串动作影响最终结果
- **没有标准答案**的问题：什么是"好的焊缝"？写不出公式，但能让人一眼判断
- **环境能模拟**的问题：仿真器里反复试错没成本

### 不擅长 / 反直觉
- **数据极贵**的场景：每次试错代价大（如药物试验、真机训练初期），RL 需要海量交互
- **任务边界模糊**：reward 写不好就 reward hacking（agent 钻空子）
- **小数据**问题：100 条样本想训出策略，BC（模仿学习）通常比 RL 好

### 不该用 RL 的信号
- 你能写出明确数学最优公式（PID / LQR 直接能解）→ 别用 RL
- 你只想做"识别 / 分类"（监督学习就行）→ 别用 RL
- 任务不需要决策序列（一锤子买卖）→ 别用 RL

## 0a.6 为什么 2026 年了你还要学 RL

短答：**RL 是"通用决策机器"，是 LLM 后下一波 AI 浪潮的主推手**。

长一点：

1. **机器人**：四足机器狗（ANYmal、Spot、宇树）、机械臂操作、自动驾驶——核心训练范式都是 RL。
2. **LLM 对齐**：ChatGPT 之所以好用，是因为 RLHF（基于人类反馈的 RL）。这是 RL 第一次出圈到大众视野。
3. **VLA（视觉-语言-动作大模型）**：RT-2、OpenVLA、π₀，把 LLM 的"会说话"和 RL 的"会决策"结合，是 2025-2026 年最热的方向。
4. **基础研究**：Dreamer V3 在 Minecraft 零样本拿钻石（2024 Nature 封面），证明了 RL 通用智能的潜力。

如果你做机器人 / 具身智能 / AI 决策系统，**RL 是绕不过去的核心工具**。

## 0a.7 你将经历什么（心理建设）

学 RL 的真实曲线：

```
理解程度
   ↑
   │                                          ╭─────  L13-L16: 前沿
   │                                       ╱
   │                              ╭───────╯       L9-L12: 工程化
   │                          ╱
   │                ╭───────╯               L4-L8: 策略梯度家族
   │           ╱                              （这里数学最痛）
   │   ╭────╯                              L1-L3: 基础概念
   │  ╱
   │╱──────────────────────────────────────────────→
   0   1周    2周    1月    2月         时间
```

### 你会经历的"懵逼时刻"

- **L4 REINFORCE 的策略梯度公式**：第一次看 ∇log π · G_t 完全不知道在干嘛 → **正常**
- **L6 PPO 的 clip ratio**：为什么是 min？为什么 1±ε？→ **正常**
- **L10 SAC 的重参数化**：rsample 和 sample 有啥区别？→ **正常**
- **L13 Diffusion 的 ᾱ_t 公式**：那一堆 α 和 β 都是什么？→ **正常**

**所有这些"懵"都是必经之路**。RL 的学习曲线不是平滑的，是阶梯式的——你会卡在某一课好几天，然后某一刻突然通了。

### 防止放弃的几个原则

1. **先抓直觉，公式回头补**。看不懂公式？先记"这个算法在做什么事"，公式是为了那件事服务的。
2. **代码至少跑一遍**。看公式 vs 看 reward 曲线 vs 改一个超参看变化——三件事的理解深度差 10 倍。
3. **思考题不是考试**。答不上来不丢人，但**至少试着想 5 分钟再翻 [solutions](solutions.mdx)**。
4. **隔几天再读**。读懵了换个时间回来，常常突然通了。
5. **别被论文吓到**。RL 论文的写法极度数学化，但本质思想往往一句话能讲清。先理解思想，再啃论文。

## 0a.8 这本教程的承诺与边界

**承诺**：
- 你读完前 8 课，能从零写一个能跑的 PPO，知道每行代码为什么这么写
- 你读完 16 课，能跟懂任何一篇 2024-2026 的机器人 RL 论文（不一定能复现，但能看懂在做什么）
- 你能给 RL 在自己项目（焊接、机械臂、其它）落地做出有依据的判断

**边界**：
- 这不是数学严格教材。我们用直觉 + 代码，不证明定理
- 不深入 LLM RL（DeepSeek-R1 那种）—— 那是另一个独立方向
- 不教博弈论 RL（多智能体）—— 焊接用不到，避开
