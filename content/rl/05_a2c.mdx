# 第 5 课：A2C（Advantage Actor-Critic）
**导航**: [← L04 REINFORCE](04_reinforce.md) · [目录](README.md) · [L06 PPO ★ →](06_ppo.md)

> REINFORCE 的方差太大。这一课加一个 Critic 网络估 V(s)，把 baseline 从"全局平均"升级为"状态相关的基线"，方差大幅下降。
> A2C = Advantage（优势函数）+ Actor（策略网络）+ Critic（价值网络）。

> **前情提要**: L4 的 REINFORCE 方差太大。这一课加 critic 网络估 V，把方差压下来。

---

## 5.1 优势函数：好动作 vs 平均水平

定义：

$$
A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)
$$

直观：在状态 s 选动作 a，比"平均水平"好多少。
- A > 0：这个动作高于平均 → 加大概率
- A < 0：低于平均 → 降低概率

策略梯度从用 $G_t$ 改成用 $A_t$：

$$
\nabla_\theta J = \mathbb{E}\left[\sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot A_t\right]
$$

期望值不变（无偏），但**方差小很多**。

---

## 5.2 优势怎么估

最简单的 1-step 估计：

$$
A_t \approx r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)
$$

这是 TD error。$V_\phi$ 是 Critic 网络。

更准的 n-step：

$$
A_t = r_t + \gamma r_{t+1} + \cdots + \gamma^{n-1} r_{t+n-1} + \gamma^n V_\phi(s_{t+n}) - V_\phi(s_t)
$$

n 越大方差越大但 bias 越小。Lesson 6 的 GAE 是这一切的统一。

## 5.3 完整 A2C 代码

```python
import gymnasium as gym
import torch
import torch.nn as nn
import torch.optim as optim
from torch.distributions import Categorical

class ActorCritic(nn.Module):
    def __init__(self, obs_dim, n_act):
        super().__init__()
        self.shared = nn.Sequential(
            nn.Linear(obs_dim, 128), nn.ReLU(),
            nn.Linear(128, 128), nn.ReLU(),
        )
        self.actor = nn.Linear(128, n_act)
        self.critic = nn.Linear(128, 1)

    def forward(self, s):
        h = self.shared(s)
        return self.actor(h), self.critic(h).squeeze(-1)

env = gym.make("CartPole-v1")
ac = ActorCritic(4, 2)
opt = optim.Adam(ac.parameters(), lr=3e-3)
gamma = 0.99

for ep in range(500):
    s, _ = env.reset()
    log_probs, values, rewards = [], [], []
    done = False
    while not done:
        logits, v = ac(torch.tensor(s, dtype=torch.float32))
        dist = Categorical(logits=logits)
        a = dist.sample()
        log_probs.append(dist.log_prob(a))
        values.append(v)
        s, r, term, trunc, _ = env.step(a.item())
        rewards.append(r)
        done = term or trunc

    # 算 returns
    G = 0
    returns = []
    for r in reversed(rewards):
        G = r + gamma * G
        returns.insert(0, G)
    returns = torch.tensor(returns, dtype=torch.float32)

    log_probs = torch.stack(log_probs)
    values = torch.stack(values)

    advantages = returns - values.detach()  # 注意 detach（critic 的梯度走另一条）

    actor_loss = -(log_probs * advantages).mean()
    critic_loss = (values - returns).pow(2).mean()
    entropy = -(log_probs * log_probs.exp()).mean()  # 鼓励探索

    loss = actor_loss + 0.5 * critic_loss - 0.01 * entropy

    opt.zero_grad()
    loss.backward()
    opt.step()

    if ep % 20 == 0:
        print(f"ep {ep}, return {sum(rewards):.1f}")
```

500 episodes 能稳定到 400+ 平均回报，比 REINFORCE 显著。

---

## 5.4 关键工程细节

1. **共享 backbone**：Actor 和 Critic 共享前面几层网络，参数效率高。
2. **`advantages = returns - values.detach()`**：detach 的原因是 advantage 是给 actor 用的"权重"，不该让梯度回流到 critic。
3. **Critic loss 权重 0.5**：经验值，让 actor 和 critic 平衡。
4. **Entropy 项**：鼓励策略保持多样，防止过早收敛。0.01 是常用系数，CartPole 这种简单任务可以更小。

---

## 5.5 A2C vs A3C
- **A3C**（Asynchronous Advantage Actor-Critic, 2016）：多线程异步收集数据，CPU 时代的产物。
- **A2C**：A3C 的同步版，多个 env 并行收集再统一更新，GPU 友好。
- 现在主流是 A2C 路线。

---

## 本课收获

> Advantage = G - V 是 RL 后续算法的通用基础概念。GAE / PPO / SAC 全用它。

## 5.6 思考题

1. 为什么 advantage 要 detach？如果不 detach 会怎样？
2. Critic loss 用 returns 当目标，为什么不是 TD error？两种写法是否等价？
3. Entropy 系数 0.01 改成 0.1 会怎样？改成 0 呢？
4. 如果 Actor 和 Critic 完全分开（不共享 backbone），会有什么变化？
5. **开放题**：A2C 比 REINFORCE 方差小，但训练时间反而可能更长，为什么？
