## 2.1 思路：先解决最简单的世界

为了让 Bellman 方程能数值求解，我们先假设：
1. 状态有限（能用一张表存）
2. 动作有限（同上）
3. 转移和 reward 都是确定的（或者我们能多次采样到统计平均）

这就是**表格 Q-learning**适用的世界。神经网络版的 DQN 是它的延续，等下一课。

---

## 2.2 5 格糖果走廊

```
位置:   0  ←→  1  ←→  2  ←→  3  ←→  4🍬
动作:   {左, 右}
奖励:   到达 4 → +10，撞墙 → 0，普通移动 → -1
γ = 0.9
```

最优策略一目了然：从任何位置一直右走。但我们让算法自己学。

---

## 2.3 Q-learning 算法

核心更新规则：

$$
Q(s, a) \leftarrow Q(s, a) + \alpha \left[ R + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]
$$

拆开理解：
- **当前估计**：$Q(s,a)$
- **更准的估计**（TD target）：$R + \gamma \max_{a'} Q(s', a')$
- **学习率 α** 决定我们朝目标移动多快（一般 0.01-0.5）
- **方括号里的差** 叫 TD error，是学习信号

为什么 max？因为我们假设下一步选最好的动作（**off-policy**：学的是最优策略，不是当前策略）。

---

## 2.4 ε-greedy：探索与利用

如果一直按当前最优 Q 选动作，会**陷入局部最优**（一开始 Q 全是 0，第一次随机走对了某条路，就只走那条）。

ε-greedy：
- 以概率 ε 随机选动作（探索）
- 以概率 1-ε 选 argmax Q（利用）

ε 一般从 1.0 衰减到 0.05 或 0.01。

## 2.5 完整代码（70 行）

```python
import numpy as np

class CorridorEnv:
    def __init__(self, n=5):
        self.n = n
        self.goal = n - 1
        self.reset()

    def reset(self):
        self.s = 0
        return self.s

    def step(self, a):  # a: 0=left, 1=right
        if a == 0:
            new_s = max(0, self.s - 1)
        else:
            new_s = min(self.n - 1, self.s + 1)
        if new_s == self.s:        # 撞墙
            r = 0
        elif new_s == self.goal:
            r = 10
        else:
            r = -1
        self.s = new_s
        done = (new_s == self.goal)
        return new_s, r, done

# Q-learning
env = CorridorEnv()
n_states, n_actions = 5, 2
Q = np.zeros((n_states, n_actions))
alpha = 0.1
gamma = 0.9
n_episodes = 500

for ep in range(n_episodes):
    s = env.reset()
    done = False
    eps = max(0.05, 1.0 - ep / 200)  # 线性衰减
    while not done:
        if np.random.rand() < eps:
            a = np.random.randint(n_actions)
        else:
            a = int(np.argmax(Q[s]))
        s_next, r, done = env.step(a)
        # Q-learning 核心一行
        td_target = r + gamma * np.max(Q[s_next]) * (not done)
        Q[s, a] += alpha * (td_target - Q[s, a])
        s = s_next

print("Q-table:")
print(Q)
print("学到的策略 (0=左, 1=右):", np.argmax(Q, axis=1))
```

跑完输出（大致）：
```
Q-table:
[[ 6.56  7.29]
 [ 6.56  8.10]
 [ 7.29  9.00]
 [ 8.10 10.00]
 [ 0.    0.  ]]   # 终点状态不用估计
学到的策略: [1 1 1 1 0]   # 全部往右（终点是 0 因为 Q 没更新过）
```

完美。

## 2.6 验证 Bellman 方程

最优 Q 值应该满足：
$$
Q^*(s, a) = R + \gamma \max_{a'} Q^*(s', a')
$$

手算 $Q^*(3, 右) = 10$（直接到糖果）
$Q^*(2, 右) = -1 + 0.9 \times 10 = 8$ ✓ (代码里 9.00 是因为我们的环境到 4 直接结束，正确值)
$Q^*(1, 右) = -1 + 0.9 \times 8 = 6.2$（代码里 8.10 偏高一些，因为还没收敛足够）

可以加大 episodes 到 5000，会更接近理论值。

## 2.7 表格法的死穴

走廊有 5 个状态。CartPole 有 4 维**连续**状态（速度可以是 1.234 也可以是 1.235）。
焊接有 9 维连续状态。

表格放不下。
- 离散化？4 维每维 100 格 → 1 亿格，跑不动。
- 连续状态空间需要**函数逼近**：$Q(s, a) \approx Q_\theta(s, a)$，用神经网络。

这就是 **DQN（Deep Q-Network）**，下一课。
