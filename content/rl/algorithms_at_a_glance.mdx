## 选型决策树

```
你的问题 ──── 是 RL 问题吗?
                │
                ├─ 不是（监督 / 优化）→ 用 SL / scipy / cvxpy
                │
                └─ 是 RL → 看下面
                
                能写出动力学方程?
                ├─ 能且线性 ──→ LQR
                ├─ 能但非线性 ──→ MPC
                └─ 不能 / 视觉感知主导 → 看下面
                
                有专家示教?
                ├─ 有，且只想模仿 → BC
                ├─ 有，单峰任务 → BC + RL fine-tune
                ├─ 有，多模态任务 → Diffusion Policy
                ├─ 有，希望大模型先验 → OpenVLA + LoRA
                └─ 无 / 想从零学 → 看下面
                
                能写出 reward function?
                ├─ 能 → 看下面
                └─ 不能但有人能比对优劣 → RLHF / DPO
                
                动作空间?
                ├─ 离散小 → DQN / Double DQN
                ├─ 离散大 / 组合 → PPO（softmax 输出）
                ├─ 连续 → 看下面
                
                重视样本效率（仿真贵 / 真机训练）?
                ├─ 是 → SAC
                ├─ 不重要（仿真便宜，并行）→ PPO
                
                任务超长 / 需要规划?
                └─ 考虑 Dreamer / World Model
```

## 各算法一句话灵魂

- **Q-learning**：用 Bellman 方程递归学最优 Q 值
- **DQN**：把 Q 表换成神经网络 + 用 Replay Buffer + Target Network 让训练稳定
- **REINFORCE**：直接对策略求梯度，乘以累积回报当权重
- **A2C**：加 critic 估 V，让 advantage 取代 raw return 降方差
- **PPO**：clip importance ratio，让一批数据可以多次复用而不崩
- **LQR**：线性二次问题的解析最优解，一个矩阵搞定
- **MPC**：每步用模型预测未来 N 步求解最优，rolling 执行
- **SAC**：在 reward 里加策略熵，鼓励探索 + 用 twin Q 防过估计
- **BC**：把示教 (s, a) 当监督学习数据
- **DAgger**：让专家在策略遇到的新状态上继续标注
- **Diffusion Policy**：用扩散模型生成动作，能拟合任意复杂多模态分布
- **Dreamer**：学环境模型，让策略在"想象的世界"里训练
- **VLA**：动作 token 加进 LLM 词表，让 LLM 输出机器人动作
- **RLHF**：从人选偏好学 reward 模型，再 PPO 优化
- **DPO**：跳过 reward model，直接从偏好对训策略

## 何时用何时不用

### 工业首选
- 离散 + simple → **DQN**
- 连续 + sim2real → **PPO + 大量 domain randomization**
- 连续 + 真机训练（贵）→ **SAC**
- 有示教 + 短任务 → **BC**（必要时 + RL fine-tune）
- 有示教 + 多模态 → **Diffusion Policy**

### 不要轻易上手
- **Dreamer V3**：训练复杂度高，团队需 ML 工程师持续维护
- **VLA from scratch**：需要 GPU 集群 + 海量数据，初创团队建议直接用 OpenVLA 微调
- **RLHF**：先确认 reward function 真的写不出来，再做。偏好数据采集贵

### 几乎从不用
- **REINFORCE**：方差太大，A2C/PPO 已经替代它
- **TRPO**：被 PPO 全面替代
- **DDPG**：被 TD3 和 SAC 替代
- **GAIL**：训练不稳定，被 BC + RL 或 RLHF 替代

## "我不懂数学，先掌握哪几个就够"

如果只能选 3 个深啃：
1. **PPO**（机器人 RL 事实标准）
2. **BC**（最简单实用基线）
3. **SAC**（连续控制 SOTA）

这三个吃透，你能解决 80% 的实际问题。

如果再加 2 个看趋势：
4. **Diffusion Policy**（2023+ 模仿学习新范式）
5. **OpenVLA**（2024+ 通用机器人方向）
