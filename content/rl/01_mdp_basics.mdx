# 第 1 课：MDP 与 RL 五要素

> 目标：搞清楚"强化学习到底在解什么数学问题"。
> 这一课没有训练，没有神经网络，只有定义和直觉。但**没读懂这一课，后面全是空中楼阁**。

> **前情提要**: 你在 0a 软启动里见过 RL 的直觉。这一课把那个直觉变成可数学描述的'五要素 (S, A, P, R, γ)'。

---

## 1.1 一个具体场景

你有一台机械臂在焊接。它每隔 50 毫秒：
1. **看**一眼焊缝（相机图像 + 关节角）
2. **决定**下一步焊枪往哪移动
3. **得到**反馈：焊缝偏移多少、电弧稳不稳

它要学的是：**根据看到的，做出最好的决定**。

强化学习给这件事一个统一的数学框架，叫 **MDP（Markov Decision Process，马尔可夫决策过程）**。

---

## 1.2 五个核心要素 —— 用糖果走廊讲清楚

**先建立直觉**。想象一个 3 格走廊：

```
[ 起点 ] —— [ 中间 ] —— [ 终点🍬 ]
   位置0      位置1       位置2
```

你是个小机器人，想拿到糖果。每一步可以**左走**或**右走**。
- 走到位置 2 拿到糖果，奖励 +10
- 撞墙（位置 0 还往左 / 位置 2 还往右）什么也得不到，奖励 0
- 普通移动，奖励 -1（每多走一步都"扣体力"）

这个 5 要素分别是：

### 要素 1：**S（状态空间）** —— "我现在在哪？"
$S = \{0, 1, 2\}$ —— 三个位置就是三种可能的状态。
对焊接：状态 = 关节角度 + 焊缝相对位置 + 电流值。维度高得多但概念一样。

### 要素 2：**A（动作空间）** —— "我能做什么？"
$A = \{\text{左}, \text{右}\}$ —— 两个动作。
对焊接：动作 = 焊枪 6 维速度向量。连续值。

### 要素 3：**P（转移概率）** —— "做了这事我会去哪？"
$P(s' \mid s, a)$：在 $s$ 做 $a$ 之后到 $s'$ 的概率。

走廊例子（确定性）：
- $P(1 \mid 0, 右) = 1$（在位置 0 往右走，100% 到位置 1）
- $P(0 \mid 0, 左) = 1$（撞墙原地不动）

焊接现实是**带噪声**的：你想让焊枪走 1mm，可能走了 0.95-1.05mm。

### 要素 4：**R（奖励函数）** —— "做了这事我得到什么？"
$R(s, a, s')$：转移瞬间的标量回报。

走廊：
- $R(1, 右, 2) = +10$（拿到糖果）
- $R(0, 右, 1) = -1$（普通移动扣体力）
- $R(0, 左, 0) = 0$（撞墙）

### 要素 5：**γ（折扣因子）** —— "我多看重未来？"
$\gamma \in [0, 1)$，通常 0.9 / 0.95 / 0.99。

**直觉**：γ 是"耐心条"。
- $\gamma = 0$：只看眼前一步，不管以后
- $\gamma \to 1$：一视同仁地在乎所有未来

未来 t 步的奖励要乘 $\gamma^t$ 折扣。$\gamma=0.9$ 时：
- 下一步 reward × 0.9
- 两步后 × 0.81
- 十步后 × 0.35
- 一百步后 × 2.7e-5（基本不在乎）

## 1.3 累积回报与目标

策略 $\pi(a \mid s)$ 是**"在状态 s 选动作 a 的概率"**。

从某个起点开始，按策略走下去，累积折扣回报：

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

具体走廊例子（起点位置 0，策略全往右，γ=0.9）：

| 步骤 | 动作 | 转到 | 即时 reward |
|---|---|---|---|
| 0 | 右 | 1 | -1 |
| 1 | 右 | 2 | +10 |

$G_0 = -1 + 0.9 \times 10 = -1 + 9 = 8$

如果走得更绕呢？比如先撞墙再走（左、右、右）：
$G_0 = 0 + 0.9 \times (-1) + 0.81 \times 10 = -0.9 + 8.1 = 7.2$

可以看到：**绕路会被 γ 惩罚**。这就是 γ 的作用：让策略偏好"快速达成目标"。

**RL 的目标**就是找一个策略 $\pi^*$，最大化期望累积回报：

$$
\pi^* = \arg\max_\pi \mathbb{E}_\pi[G_0]
$$

---

## 1.4 价值函数 V 和 Q

两个核心量你必须背：

**状态价值函数 V**：从状态 s 出发，按策略 π 走下去，期望能拿多少。
$$
V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]
$$

**动作价值函数 Q**：在状态 s 选动作 a 之后再按 π 走下去，期望能拿多少。
$$
Q^\pi(s, a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]
$$

**两者关系**：
$$
V^\pi(s) = \sum_a \pi(a \mid s) Q^\pi(s, a)
$$

直观：状态价值 = 各动作价值按策略概率加权。

---

## 1.5 Bellman 方程（一切的根源）

把 $G_t = R_{t+1} + \gamma G_{t+1}$ 代进去：

$$
V^\pi(s) = \mathbb{E}_\pi[R_{t+1} + \gamma V^\pi(s_{t+1}) \mid s_t = s]
$$

$$
Q^\pi(s, a) = \mathbb{E}[R_{t+1} + \gamma V^\pi(s_{t+1}) \mid s_t=s, a_t=a]
$$

**这个递归关系叫 Bellman 方程**，是 RL 的发动机。后面 Q-learning、DQN、PPO 全都从它生出来。

直觉：**当前状态的价值 = 即时奖励 + 折扣后的下一状态价值**。

## 1.6 第一个代码：和环境互动

```python
import gymnasium as gym

env = gym.make("CartPole-v1")
obs, info = env.reset(seed=42)
total = 0
for step in range(500):
    action = env.action_space.sample()  # 随机
    obs, reward, terminated, truncated, info = env.step(action)
    total += reward
    if terminated or truncated:
        print(f"died at step {step}, total={total}")
        obs, info = env.reset()
        total = 0
env.close()
```

CartPole 任务：让小车上的杆不要倒。
- 状态 $s$：4 维（位置、速度、角度、角速度）
- 动作 $a$：2 个（左推、右推）
- 奖励：每存活一步 +1
- 终止：杆角度 > 12° 或小车跑出边界

随机策略平均能撑 20 步左右。RL 的目标是学一个策略撑满 500 步。

## 1.7 焊接场景的 MDP 化

| 要素 | 焊接对应 |
|---|---|
| S | (关节角 6 维, 焊缝偏移 2 维, 电流 1 维) = 9 维 |
| A | 6 维末端速度增量 |
| P | 真实物理 + 焊接随机扰动 |
| R | -focal偏移 - 飞溅惩罚 + 完工奖励 |
| γ | 0.99（焊一段缝长达数千步，需要看远）|

后面所有算法都在这个 MDP 上发力。

> RL 五要素是后续所有算法的'乐高积木'。任何论文你都能问一遍：它的 S/A/P/R/γ 分别是什么？

## 1.8 思考题

1. 为什么 γ 不能等于 1？提示：考虑无穷长 episode 的累积回报。
2. 走廊例子里如果改成"撞墙 reward = -100"，最优策略会变吗？为什么 γ 没有出现在你的答案里？
3. V 和 Q 哪个更"细粒度"？为什么 RL 算法基本都学 Q 而不是 V？
4. Bellman 方程为什么叫"递归"？把它和"动态规划"联系起来想。
5. **开放题**：把"开车从北京到上海"建成一个 MDP，五要素分别是什么？给出三种合理的 R 设计。
